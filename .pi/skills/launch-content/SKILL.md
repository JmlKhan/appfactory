# Launch content

Inputs: BRIEF.md (user, differentiator, tone), STORE.md.
Output: `docs/LAUNCH.md`.

1. **Angles**: 5 content angles tied to the target user's real pain (not features). One line each + why it should spread.
2. **Scripts**: 10 short-video scripts (15–30s) in Uzbek (and Russian variants for the top 3): hook (first 2s, on-screen text), shots list, voiceover/caption, CTA. Mark which need the app screen recorded vs talking head.
3. **Posting plan**: 14 days — platform, which script, time; reuse each video across Instagram Reels, TikTok, YouTube Shorts, Telegram.
4. **Measurement**: what to track per post (views, saves, profile visits, link clicks) and the kill/double-down rule after 7 days.
5. **In-app loop**: share/referral moment, rating prompt timing (after a success moment, never on first launch).
Keep it practical: filmable by one person with an iPhone.
